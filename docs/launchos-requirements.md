# LaunchOS 功能需求文档

## 1. 文档信息

- 产品名称：LaunchOS
- 产品定位：macOS 26 Tahoe 的 Launchpad 替代品
- 文档类型：产品需求文档（PRD）
- 当前阶段：需求整理 / MVP 规划
- 参考来源：
  - [LaunchOS 官网](https://launchosapp.com/)
  - [LaunchOS Features](https://launchosapp.com/features/)
  - [LaunchOS Release Notes](https://launchosapp.com/release.en)

## 2. 产品背景

macOS 26 Tahoe 中，部分用户仍然依赖传统 Launchpad 的全屏网格、分页、文件夹、拖拽整理、F4 启动、触控板手势和热角等使用习惯。Spotlight 能快速搜索应用，但不能替代 Launchpad 的视觉化整理和空间记忆。

LaunchOS 的目标是恢复并增强旧版 Launchpad 的核心体验，让用户在 macOS 26 上继续通过熟悉的方式浏览、搜索、组织和启动应用。

## 3. 产品目标

1. 提供接近原生 Launchpad 的全屏应用网格体验。
2. 支持用户通过快捷键、F4、触控板手势、热角、Dock、菜单栏等方式快速唤起。
3. 支持应用搜索、分页浏览、拖拽排序、文件夹管理和右键快捷操作。
4. 支持自定义布局、隐藏应用、自定义应用来源和布局备份恢复。
5. 适配 macOS 26 Tahoe 的 Liquid Glass 视觉风格。
6. 保持流畅、稳定、接近系统级组件的体验。

## 4. 非目标

1. 不做通用命令面板或 Spotlight 替代品。
2. 不以复杂自动化、脚本执行或插件市场为主要方向。
3. 不优先实现跨平台版本，仅面向 macOS 26 Tahoe。
4. 不优先实现 App Store 分发模式，因为系统级手势和按键能力可能受限。

## 5. 目标用户

### 5.1 旧 Launchpad 重度用户

- 习惯使用 F4、触控板捏合或热角打开 Launchpad。
- 依赖应用图标位置和页面顺序形成空间记忆。
- 需要完整保留分页、文件夹和拖拽整理体验。

### 5.2 多应用工作流用户

- 安装应用数量较多。
- 需要按工作、生活、开发、设计等场景整理应用。
- 需要隐藏低频或系统辅助应用，减少视觉噪音。

### 5.3 多设备 / 多显示器用户

- 使用多个 Mac 或多个显示器。
- 希望布局可备份、迁移和恢复。
- 希望 Launchpad 出现在主屏、当前屏或鼠标所在屏。

## 7. 详细功能需求

### 7.1 启动与关闭

#### 7.1.1 Dock 图标启动

用户可以点击 Dock 中的应用图标打开 LaunchOS 主界面。

验收标准：

- 点击 Dock 图标后显示主界面。
- 如果主界面已显示，再次点击 Dock 图标应聚焦或切换显示状态。
- 启动过程无明显卡顿。

#### 7.1.2 菜单栏启动

用户可以通过菜单栏图标打开 LaunchOS，适合隐藏 Dock 的用户。

验收标准：

- 菜单栏图标常驻可见。
- 点击菜单栏图标可打开主界面。
- 菜单栏菜单包含设置、检查更新、退出等入口。

#### 7.1.3 全局快捷键启动

用户可以配置一个全局快捷键打开或关闭 LaunchOS。

验收标准：

- 支持用户在设置中录入快捷键。
- 快捷键在应用后台运行时仍可触发。
- 主界面已打开时，再次触发快捷键可关闭。
- 快捷键冲突时给出提示。

#### 7.1.4 F4 键启动

用户可以使用系统 F4 键打开 LaunchOS，恢复旧 Launchpad 的键盘习惯。

验收标准：

- 支持启用或关闭 F4 接管。
- 兼容新旧 Mac 键盘映射差异。
- 如果系统或其他应用占用 F4，应给出冲突提示。

#### 7.1.5 触控板手势启动

用户可以通过三指、四指或五指捏合手势打开 LaunchOS。

验收标准：

- 支持四指或五指捏合。
- 支持三指捏合作为可选模式。
- 手势过程中主界面透明度和缩放跟随手势进度。
- 系统 Show Desktop 手势保持正常。
- 避免与系统三指拖移产生明显冲突。

#### 7.1.6 热角启动

用户可以将鼠标移动到指定屏幕角落打开或关闭 LaunchOS。

验收标准：

- 支持选择触发角落。
- 支持多显示器。
- 仅响应相邻有效角落，减少误触。
- 与 macOS 系统热角冲突时给出提醒。

#### 7.1.7 自然关闭行为

用户可以通过符合 Launchpad 习惯的方式关闭主界面。

验收标准：

- 点击空白区域关闭。
- 按 Esc 关闭。
- 再次执行启动动作关闭。
- 使用展开手势关闭。
- 文件夹、搜索、拖拽状态下的 Esc 行为符合上下文。

### 7.2 应用浏览与分页

#### 7.2.1 全屏网格展示

主界面以全屏网格展示应用图标和名称。

验收标准：

- 图标、名称、分页指示器布局稳定。
- 应用名称过长时不撑破布局。
- 图标尺寸根据屏幕空间自适应。
- Dock 占用空间变化后布局可正确重算。

#### 7.2.2 横向分页浏览

用户可以像旧 Launchpad 一样横向翻页浏览应用。

验收标准：

- 支持鼠标滚轮分页。
- 支持触控板横向滑动分页。
- 支持鼠标拖拽分页。
- 支持键盘 `Command + Left` 和 `Command + Right` 分页。
- 翻页动画连续、流畅。

#### 7.2.3 纵向滚动模式

用户可以切换为纵向滚动视图浏览应用。

验收标准：

- 设置中可切换横向分页和纵向滚动。
- 纵向滚动时搜索、拖拽、文件夹仍可用。
- 关闭后可记住用户选择。

#### 7.2.4 鼠标兼容性

需要兼容精确滚轮、平滑滚轮和第三方鼠标工具。

验收标准：

- 平滑滚轮不会一次触发多次翻页。
- Logitech Options+ 等工具下滚动行为正常。
- 支持鼠标侧键翻页。

#### 7.2.5 记住上次位置

用户可以选择再次打开时回到上次位置或首页。

验收标准：

- 支持重新打开时停留在上次页面或位置。
- 支持始终回到首页。
- 支持关闭后一段自定义延迟再回到首页。

### 7.3 键盘控制

#### 7.3.1 方向键导航

用户可以使用方向键在应用和文件夹之间移动高亮。

验收标准：

- 方向键移动高亮状态。
- 横向分页模式中，目标项在其他页面时自动翻页。
- 纵向滚动模式中，目标项自动滚动到可见区域。

#### 7.3.2 Enter 打开

用户可以按 Enter 打开当前高亮的应用或文件夹。

验收标准：

- 高亮 App 时按 Enter 启动应用。
- 高亮文件夹时按 Enter 打开文件夹。
- 进入文件夹后默认高亮第一个应用。

#### 7.3.3 Esc 上下文行为

Esc 应根据当前上下文执行取消或关闭。

验收标准：

- 搜索中按 Esc 清空搜索。
- 文件夹打开时按 Esc 关闭文件夹。
- 重命名时按 Esc 取消重命名。
- 拖拽时按 Esc 取消拖拽。
- 主界面空闲时按 Esc 关闭主界面。

### 7.4 搜索

#### 7.4.1 自动聚焦搜索

主界面打开时，搜索框自动获得焦点。

验收标准：

- 用户无需点击即可输入搜索词。
- 搜索框聚焦不影响键盘导航和快捷键。

#### 7.4.2 实时搜索

用户输入内容后，结果实时更新。

验收标准：

- 输入变化后立即刷新结果。
- 搜索结果为空时显示空状态。
- 搜索后按 Enter 打开最佳匹配应用。

#### 7.4.3 匹配逻辑

搜索应覆盖应用显示名、默认名和用户自定义别名。

验收标准：

- 支持子串匹配。
- 支持英文首字母匹配。
- 支持缩写匹配。
- 支持 CamelCase 匹配。
- 结果按匹配质量排序。

#### 7.4.4 中文匹配优化

中文应用名称应支持拼音检索。

验收标准：

- 支持全拼匹配。
- 支持拼音首字母匹配。
- 中英文混合应用名可以正常搜索。

### 7.5 应用管理

#### 7.5.1 应用扫描

系统需要扫描并展示可启动应用。

验收标准：

- 默认扫描系统 Applications 目录。
- 默认扫描用户 Applications 目录。
- 支持 alias 类型应用。
- 排除嵌套在其他 `.app` 内部的应用。
- 重复应用按真实路径和标识符去重。

#### 7.5.2 打开应用

用户点击或键盘确认后可以打开应用。

验收标准：

- 点击 App 图标打开应用。
- 搜索结果点击或 Enter 打开应用。
- 打开应用后关闭 LaunchOS 主界面。
- 避免同一应用被异常启动为多个实例。

#### 7.5.3 拖拽排序

用户可以拖拽应用调整顺序。

验收标准：

- 拖拽时显示位置预览动画。
- 拖拽过程不卡顿。
- 拖到页面边缘自动翻页。
- 拖到最后一页边缘可创建新页面。
- 排序结果持久化保存。

#### 7.5.4 多种排序模式

用户可以选择应用排序方式。

验收标准：

- 支持手动排序。
- 支持按名称排序。
- 支持按添加日期排序。
- 支持按最近打开日期排序。
- 切换排序模式时给出必要确认，避免误改用户手动布局。

#### 7.5.5 应用重命名

用户可以为应用设置自定义显示名或别名。

验收标准：

- 支持从右键菜单重命名。
- 重命名输入框自动聚焦。
- 自定义名称参与搜索。
- 支持恢复默认名称。

#### 7.5.6 隐藏应用

用户可以隐藏不希望展示的应用。

验收标准：

- 支持从右键菜单隐藏应用。
- 隐藏应用不再出现在主界面和搜索结果中。
- 设置中的应用管理页可以恢复隐藏应用。

### 7.6 文件夹管理

#### 7.6.1 创建与合并文件夹

用户可以通过拖拽应用创建和管理文件夹。

验收标准：

- 将一个应用拖到另一个应用上可创建文件夹。
- 将应用拖到已有文件夹中心可加入文件夹。
- 右键菜单可将应用移动到指定文件夹。

#### 7.6.2 打开与关闭文件夹

用户可以打开文件夹查看内部应用。

验收标准：

- 点击文件夹打开。
- 高亮文件夹时按 Enter 打开。
- 点击文件夹外空白区域关闭。
- 按 Esc 关闭。

#### 7.6.3 重命名文件夹

用户可以修改文件夹名称。

验收标准：

- 点击展开后的文件夹标题可重命名。
- 右键菜单可重命名文件夹。
- 重命名后立即反映在 UI 上。

#### 7.6.4 解散文件夹

用户可以手动解散文件夹，或在只剩一个应用时自动解散。

验收标准：

- 文件夹只剩一个应用时自动解散。
- 右键菜单可解散文件夹。
- 解散后应用尽量回到原始附近位置。

### 7.7 右键快捷菜单

#### 7.7.1 App 右键菜单

用户右键 App 后可以快速执行常用操作。

菜单项：

- 在 Finder 中显示
- 移动到文件夹
- 隐藏应用
- 重命名 / 设置别名
- 干净卸载（后续版本）

验收标准：

- 菜单项根据当前状态启用或禁用。
- 操作完成后 UI 即时更新。

#### 7.7.2 文件夹右键菜单

用户右键文件夹后可以管理文件夹。

菜单项：

- 重命名文件夹
- 解散文件夹

验收标准：

- 文件夹为空或异常状态时菜单仍稳定。
- 解散前可根据风险提示用户确认。

#### 7.7.3 空白区域右键菜单

用户右键空白区域后可以调整全局设置。

菜单项：

- 打开设置
- 切换排序模式
- 切换浏览模式
- 检查更新
- 退出应用

### 7.8 布局与多显示器

#### 7.8.1 自定义网格布局

用户可以独立设置每页列数和行数。

验收标准：

- 支持设置列数。
- 支持设置行数。
- 图标大小自动适配可用空间。
- 调整布局时可选择是否重新排列应用。

#### 7.8.2 自动尺寸适配

系统根据屏幕、网格数量和 Dock 占用空间自动计算图标大小。

验收标准：

- 大屏上布局不过度拉宽。
- 小屏上图标和文字不重叠。
- Dock 位于左、右、底部时布局均正常。

#### 7.8.3 多显示器策略

用户可以选择 LaunchOS 显示在哪个屏幕。

选项：

- 主显示器
- 当前活动显示器
- 鼠标所在显示器

验收标准：

- 显示器连接或断开后自动重算布局。
- 热角在多显示器环境下触发准确。

### 7.9 外观

#### 7.9.1 背景模式

用户可以选择不同背景样式。

选项：

- 使用系统壁纸
- 使用系统壁纸但关闭模糊
- 使用玻璃材质背景
- 调整玻璃材质强度

验收标准：

- 壁纸变化后背景及时更新。
- 动态壁纸可正常显示。
- 深色 / 浅色模式下可读性良好。

#### 7.9.2 Tahoe / Liquid Glass 风格

界面视觉应符合 macOS 26 Tahoe 的系统语言。

验收标准：

- 背景、搜索框、文件夹、菜单具有玻璃质感。
- 动效节奏接近系统组件。
- 不出现明显第三方应用的割裂感。

#### 7.9.3 图标样式

用户可以切换 LaunchOS 自身应用图标样式。

验收标准：

- 支持不同 macOS 时代的 Launchpad 风格图标。
- 图标自动适配浅色、深色和系统 tint 模式。
- 切换后图标缓存自动刷新。

### 7.10 数据与迁移

#### 7.10.1 导入原生 Launchpad 布局

用户可以导入旧 Launchpad 的排序、分页和文件夹数据。

验收标准：

- 支持导入应用顺序。
- 支持导入分页信息。
- 支持导入文件夹结构。
- 导入失败时保留当前布局并提示原因。

#### 7.10.2 布局备份与恢复

用户可以导出和导入 LaunchOS 布局。

验收标准：

- 支持导出布局备份文件。
- 支持从备份文件恢复。
- 恢复前提示会覆盖当前布局。
- 备份包含应用顺序、文件夹、自定义名称、隐藏状态和布局设置。

#### 7.10.3 自定义应用来源

用户可以添加额外应用目录。

验收标准：

- 支持添加外部磁盘目录。
- 支持添加虚拟机或开发环境中的应用目录。
- 扫描失败时不影响默认目录应用。
- 用户可以移除自定义来源。

### 7.11 设置与授权

#### 7.11.1 设置面板

系统需要提供统一设置入口。

设置项：

- 启动方式
- 快捷键
- F4 接管
- 手势设置
- 热角设置
- 浏览模式
- 网格布局
- 显示器策略
- 背景与外观
- 应用来源
- 隐藏应用管理
- 备份与恢复
- 关于与设备管理

验收标准：

- `Command + ,` 可打开设置。
- 设置窗口支持 Esc 关闭。
- 设置修改后及时生效或明确要求重启。

#### 7.11.2 Basic / Pro 授权

产品支持免费 Basic 和付费 Pro。

Basic 建议包含：

- Dock / 菜单栏启动
- 全局快捷键
- 全屏网格
- 横向分页
- 应用搜索
- 基础文件夹和拖拽整理

Pro 建议包含：

- 触控板手势启动
- 热角启动
- F4 启动
- 自定义网格布局
- 纵向滚动模式
- 应用重命名
- 自定义应用来源
- 隐藏应用
- 未来的窗口模式和干净卸载

验收标准：

- Pro 提供 7 天试用。
- 授权支持设备管理。
- 更换设备时允许移除旧设备。
- 网络或激活失败时给出清晰错误说明。

### 7.12 未来功能

#### 7.12.1 窗口化浏览模式

提供类似 Apps.app 的轻量窗口模式，同时保留排序和文件夹管理。

优先级：P2

#### 7.12.2 干净卸载应用

卸载应用时清理应用本体、设置、缓存和相关残留文件。

优先级：P2

验收标准：

- 卸载前展示将删除的文件清单。
- 用户确认后再执行删除。
- 删除失败时展示失败项。
- 不删除无法确认归属的用户数据。

## 8. 非功能需求

### 8.1 性能

- 主界面打开应尽可能接近即时响应。
- 搜索输入无明显延迟。
- 分页、拖拽、文件夹展开动画保持流畅。
- 后台运行时资源占用应低。

### 8.2 稳定性

- 支持系统休眠和唤醒后的手势恢复。
- 支持全屏应用场景。
- 支持多显示器切换。
- 避免出现在 `Command + Tab` 应用切换器中，除非用户主动配置。
- 避免启动时显示主界面，应支持静默后台启动。

### 8.3 可访问性

- 所有核心操作应可通过键盘完成。
- 搜索框、应用、文件夹应有明确焦点状态。
- 文本对比度在浅色和深色模式下均可读。

### 8.4 国际化

- 简体中文
- 英文

后续支持：

- 日文
- 韩文
- 法文
- 德文
- 西班牙文
- 葡萄牙文
- 俄文
- 其他社区翻译语言

## 9. MVP 实现范围

MVP 目标是先做出可用的 Launchpad 替代体验，优先覆盖最核心的浏览、搜索、启动和整理能力。

### 9.1 MVP 必做

1. macOS 应用壳。
2. 后台常驻能力。
3. Dock 或菜单栏入口。
4. 全局快捷键打开 / 关闭。
5. 全屏应用网格。
6. 扫描系统和用户 Applications 目录。
7. 点击打开应用。
8. 搜索框自动聚焦。
9. 实时搜索。
10. 横向分页。
11. 基础拖拽排序。
12. 拖拽创建文件夹。
13. 文件夹打开、关闭、重命名。
14. 布局持久化。

### 9.2 MVP 暂缓

1. F4 接管。
2. 触控板捏合手势。

4. 原生 Launchpad 布局导入。

7. 干净卸载。
8. 窗口化浏览模式。

## 10. 推荐技术实现方向

### 10.1 原生 macOS 方案

推荐使用 Swift / SwiftUI / AppKit 实现。

原因：

- 全局快捷键、菜单栏、窗口层级、手势、热角、多显示器等能力更接近系统层。
- Liquid Glass 和 macOS 26 视觉适配更自然。
- 应用扫描、打开、Finder 集成、权限处理更直接。

### 10.2 Web / Electron 方案

可用于快速原型，但不建议作为最终方案。

风险：

- 系统级手势和 F4 接管能力受限。
- 全屏窗口、动画性能和系统一致性较难做到原生质感。
- 权限和多显示器细节更复杂。

## 12. 验收总标准

产品达到以下状态时，可认为 v1 基本完成：

1. 用户可以通过快捷键或图标打开一个接近 Launchpad 的全屏应用网格。
2. 用户可以搜索、分页、键盘导航并启动应用。
3. 用户可以拖拽排序、创建文件夹、重命名文件夹。
4. 用户布局在重启后保留。
5. 多显示器、全屏应用、系统休眠唤醒后仍保持稳定。
6. 动画、手势和视觉风格接近 macOS 原生体验。
7. 基础功能免费可用，高级功能可通过 Pro 控制。
